# 工单分类边界

| 主类别 | 适用场景 |
|---|---|
| 登录与认证 | 登录、密码重置、验证码、SSO、普通权限申请 |
| 支付与账单 | 扣款异常、退款、发票、账单疑问 |
| 功能缺陷 | 功能报错、按钮失效等，不符合更具体类别的异常 |
| 性能问题 | 卡顿、超时、页面或接口慢 |
| 数据问题 | 数据丢失、不一致、导入导出异常 |
| 咨询与使用 | 使用方法、功能支持情况、最佳实践 |
| 安全与合规 | 疑似越权、账号被盗、隐私泄露、安全事件、合规请求 |
| 其他 | 证据不足以分类，或无法归入以上类别 |

分类按主要问题，不按尚未证实的根因：
- 普通权限配置归登录与认证；疑似越权或账号失陷归安全与合规。
- 普通数据不一致归数据问题；疑似泄露归安全与合规。
- 接口缓慢或超时优先归性能问题，除非主要证据指向更具体的数据或安全风险。
- 合规流程咨询可以归安全与合规，但不自动意味着安全事故或立即升级。
- 同一工单多个问题优先选风险最高者作为主类别，摘要保留其他诉求；不要把不同客户的独立工单合并。
